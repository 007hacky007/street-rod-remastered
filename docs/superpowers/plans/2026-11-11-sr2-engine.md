# Street Rod 2 engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Street Rod 2's faithful port builds and runs from this repository as `streetrod2-enhanced`, on one
host shared with Street Rod 1, with the same comforts (window, Retina, Mac keys, separate volumes), while
Street Rod 1's compiled code stays the same.

**Architecture:** The engine-independent files (host, Mac keys, codeptr, types) move to `common/` and become
one object library both games link. The host gets a small run-time configuration (window title, audio rate,
AdLib chip, mouse space) whose default is exactly Street Rod 1's, so Street Rod 1's `main.c` does not change.
Street Rod 2's engine is imported from upstream into `src2/` with Nuked-OPL3 in `third_party/`.

**Tech Stack:** C11, SDL3, CMake 3.24, Nuked-OPL3 (LGPL-2.1+), Python 3 for the smoke test.

**Spec:** `docs/superpowers/specs/2026-11-11-street-rod-2-design.md`

**This is plan 1 of 5.** The design is split into plans that each ship something testable:
1. Engine (this plan): the split, the shared host, Street Rod 2 running.
2. Launcher and packaging: the Game choice, SR2's folder and Mac download, both executables in the app and
   the zip, CI artifacts, player docs.
3. Remastered music: the band driven by SR2's `.MUS` sequencer and by its speaker tune.
4. Enhanced race view: every SR2 race kind and the town drive.
5. Remastered pictures: dump, catalogue as source `sr2`, reuse of SR1 art, `SR2_SHP` shapes; the generation
   run only after the owner says go.
Release 0.5.0 follows plans 1 to 4.

## Global Constraints

- Street Rod 1 does not change: same behaviour, same pictures, same files, same settings.
- Street Rod 1's check is the compiled code, not demo snapshots (see "Ruling on the SR1 check" below):
  every SR1 object file except `host.c.o` disassembles identically before and after this plan.
- Upstream: `github.com/kylofon/street-rod-2-sdl3` at commit `9a3d488`, folder `sr2port/src`, MIT, Krzysztof
  Kania (already in `LICENSE`). Nuked-OPL3 from the same commit, `sr2port/third_party/nuked-opl3`, LGPL-2.1+,
  with its `LICENSE` kept beside it.
- Shared code (`common/`) includes neither game's `symbols.h`, `mem.h` or `platform/` headers.
- Executables: `streetrod-enhanced` (unchanged) and `streetrod2-enhanced`.
- Markers: our deliberate changes in either engine say `ENH:`; port fixes in SR2's engine say `PORT:` as
  upstream does.
- Only VGA for SR2: CGA, EGA, Tandy and Hercules stay parked as upstream left them.
- The SR2 game files are never committed. Tests that need them run only when
  `-DSRE_TEST_GAME2_DIR=<folder with SR2's SR.EXE>` is given (like `SRE_TEST_GAME_DIR` for SR1).
- No macOS username, real name, email or AI attribution in any committed file. Plain hyphens only, no
  Unicode dashes. Commit messages: one short imperative line, no body, no trailers.
- Git identity in this repo: `007hacky007` / `007hacky007@users.noreply.github.com`, `commit.gpgsign false`.

**Ruling on the SR1 check (deviation from the spec).** The spec asks for byte-identical demo snapshots with
`SR_SEED=3`. Measured on 2026-11-11 with the current master: two runs of the same build give different
frames, with wall-clock snapshots (7 of 9 unique frames shared) and with snapshots keyed to emulated timer
ticks (30 of 60 differ), because the host injects timer ticks by wall-clock time. Making the emulator
lockstep would change the host itself. The plan therefore pins SR1 by its compiled code (Task 1), by a
characterisation test of the host's audio and mouse (Task 3), and by the existing tests including
`identity` when `SRE_TEST_GAME_DIR` is given. Cost if wrong: a behaviour change in `host.c` that the
characterisation test does not cover would go unnoticed until a playtest.

## Review Focus

1. **SR1 audio at 44.1 kHz.** The filter constants (`HP_R 0.99715`, `LP_A 0.7603`), `SPEAKER_GAIN`,
   `MUSIC_GAIN` and the stereo output must stay exactly as they are under the default configuration; a
   recomputed constant changes every sample. Pinned by `test_host` `sr1_audio_unchanged` (Task 3).
2. **Mouse space.** SR1's enhanced frames are 320*N wide (640 at N = 2), SR2's text menus are 640x200: the
   mouse must map to 320x200 in both games' graphics screens whatever the frame size. Pinned by
   `test_host` `mouse_space` (Task 3).
3. **Effects on borrowed music voices.** SR2's effects borrow AdLib voices 2..5 from the music
   (`sound/adfx.c`): with `--music-volume 0` an effect on voice 3 must still sound, and music on voice 0 must
   not. Pinned by `test_host` `opl_voice_gain` (Task 3) and by `sr2_volumes` (Task 5).
4. **The wrong game's files.** SR1's folder given to `streetrod2-enhanced` (and the reverse) must fail with
   the game's own message and exit 1, not crash. Pinned by `sr2_check_wrong_game` (Task 4).
5. **Saved games and high scores in the game folder.** `HOTROD*.SAV` and `HALL_DAT` go through the shared
   `host_game_path` (case-insensitive). Pinned by the smoke paths `save_load` and `end_king` (Task 6).

### Task 1: SR1 compiled-code check

**Files:**
- Create: `tools/sr1-codecheck.sh`

**Interfaces:**
- Produces: `tools/sr1-codecheck.sh BASE [HEAD] [--allow NAME.o ...]`: builds Street Rod 1 at two commits
  and compares each object's disassembly. Prints one line per object (`same` / `DIFF` / `only in BASE` /
  `only in HEAD`) and a summary `N objects, M differ (allowed: ...)`. Exit 0 when every differing object is
  in the allow list, 1 otherwise.

- [ ] **Step 1: Write the script.** Each commit is exported with `git archive <rev> | tar -x` into its own
  `mktemp -d` folder (never a worktree of this repo, so nothing touches the working tree), configured with
  `cmake -S <tree> -B <tree>/b -G Ninja -DCMAKE_BUILD_TYPE=Release -DSRE_LAUNCHER=OFF -DSRE_TESTS=OFF
  -DCMAKE_PREFIX_PATH=<repo>/build-deps/prefix` (prefix from `SRE_PREFIX` if set) and built with
  `cmake --build <tree>/b --target streetrod-enhanced`. Objects are matched by source basename (they are
  unique in `src/` and stay unique in `common/`), found with `find <tree>/b -name '*.c.o'` and restricted to
  the `sre_core`, `sre_host` and `streetrod-enhanced` target folders. Each is compared as
  `objdump -d --no-show-raw-insn <obj> | tail -n +3` (drops the file-name header). Temp folders are removed
  on exit.

- [ ] **Step 2: Check it against itself**

Run: `tools/sr1-codecheck.sh HEAD HEAD`
Expected: every line `same`, summary `... 0 differ`, exit 0. If any object differs between two builds of
the same commit at different paths, the comparison is path-dependent: fix the script (e.g. add
`-ffile-prefix-map=<tree>=.` to `CMAKE_C_FLAGS`) until this passes.

### Task 3: Host configuration, AdLib chip and voice volumes

**Files:**

**Interfaces:**
- Produces (in `common/host.h`):
  ```c
  typedef struct HostConfig {
      const char *title;      /* window and message box title; default "Street Rod Enhanced" */
      int audio_rate;         /* output frames per second; default 44100. 49716 for SR2 (the OPL2 rate) */
      bool opl;               /* render an AdLib chip into the output; default false */
  } HostConfig;
  void host_configure(const HostConfig *cfg);      /* before host_init; never called by SR1 */
  void host_set_mouse_space(int w, int h);         /* screen pixels the mouse reports in; default 320x200 */
  void host_opl_enable(bool on);                   /* as upstream: reset the chip and start rendering it */
  void host_opl_write(u8 reg, u8 value);           /* as upstream, stamped at the emulated time */
  void host_opl_voice_music(int voice, bool music);/* voice 0..8 now sounds at the music (or effects) volume */
  ```
  `host_audio_rate()` returns the configured rate. `SR_AUDIO_WAV` is accepted as an alias of
  `SR_AUDIO_DUMP` (upstream's name). `host_fatal` and the window use `cfg->title`.
- Produces (in `third_party/nuked-opl3/opl3.h`): `void OPL3_SetChannelGain(opl3_chip *chip, int ch, int32_t
  gain_q16)`; gain 65536 = unchanged, set to 65536 for all 18 channels by `OPL3_Reset`.
